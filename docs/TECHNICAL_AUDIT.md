## المعمارية والقرارات

1. استكمال تطبيق Android الحالي؛ لا WebView ولا إعادة إنشاء منصة موازية.
2. `MainActivity`: العرض، دورة الحياة، البحث المؤجل 250ms، حالات الخطأ والفراغ، المفضلة المحلية والوضع البصري.
3. `CatalogDatabase`: SQLiteOpenHelper بإصدار مخطط 1، علاقات المؤلف/التصنيف/الكتاب وفهارس العلاقات وقيود الترخيص وISBN. لا حذف تلقائي لقاعدة البيانات عند الترقية.
4. `ArabicSearch`: توحيد Unicode وإزالة التشكيل والتطويل وتوحيد الألف والألف المقصورة؛ لا ادعاء تصحيح إملائي أو بحث دلالي. بحث LIKE محدود إلى 100 نتيجة مناسب فقط للفهرس الأولي الصغير، ويحتاج ترقية إلى فهرس كامل عند إدخال محتوى فعلي.
5. الاستعلامات خارج خيط الواجهة، والنتائج القديمة تُهمل عند تغير البحث. إغلاق القاعدة بعد الأعمال المنتظرة.
6. سجل توضيحي أصلي واضح؛ لا كتب منسوبة لمؤلفين بلا مصدر ولا ملفات محمية. لا تحميل أو اتصال بخدمات خارجية.
7. لا تبعيات Android إنتاجية جديدة. JUnit في الاختبارات فقط. لا مفاتيح API.

## قاعدة البيانات

`authors(id, name)` و`categories(id, name)` مرتبطتان بـ`books` بمفاتيح أجنبية مفعلة. الكتاب يحتوي العنوان والوصف وISBN والترخيص والأرشفة ونص البحث الموحد. المفضلة والوضع الليلي في SharedPreferences الخاصة بالتطبيق. لا توجد حسابات؛ المفضلة لا تتزامن. لا تضاف ملفات PDF/EPUB قبل وضع نموذج تراخيص ومسار تخزين محمي وخادم صلاحيات.
