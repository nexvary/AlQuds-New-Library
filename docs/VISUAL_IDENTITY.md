# الهوية البصرية — المرحلة 11

نسخة مرشحة 1.5.0 (17)، الحزمة org.alquds.library ومخطط SQLite 2 كما هما.

- هوية مكتبة القدس الجديدة في عنوان عربي RTL مع رمز كتب ملون. لا علامة نيكسفاري في واجهة التشغيل. لا يتضمن المستودع مصدر الواجهة القديمة المصورة.
- خمسة أصول PNG جاهزة من Microsoft Fluent Emoji، نمط 3D، دون تعديل أو صبغة أو رموز نصية بديلة. مستودع المصدر والالتزام والبصمات في `third_party/fluent-emoji/assets.json`. ترخيص MIT محفوظ في المستودع ومضمن في APK. رمز الكتب رمز منتج جاهز وليس شعارًا حصريًا.
- الكتب، البحث، المفضلة، الشمس والقمر؛ النجمة تميز الكتاب المحفوظ مع وصف عربي لقارئ الشاشة. الصور الزخرفية لا تكرر العنوان المنطوق.
- بطاقات ذات سطح أبيض/داكن وحدود وزوايا مستديرة واستجابة لمس. الأزرار بارتفاع أدنى 48dp والنصوص قابلة للالتفاف. لا يُعتمد اللون وحده لتمييز وظيفة.
- أيقونة تشغيل PNG على API 24 وadaptive icon بخلفية عاجية وهوامش حماية على API 26 وما بعده. نافذة التفاصيل تتبع الثيم المختار.
- حفظ البحث والفلتر والثيم والمفضلة، وعدم تغيير SQL أو الترحيل أو هوية توقيع التحديث.

## التحقق

نجح محليًا 28 اختبار Python وفحص السياسة والمسافات. لا توجد أدوات Android SDK/Gradle في بيئة العمل المحلية؛ البناء وlint وJUnit واختبارات API 24 و35 تنتظر GitHub Actions. يُرفق workflow المحاكيات لقطتي الشاشة النهارية والليلية من الجهاز لكل API في artifacts للمراجعة البصرية. لا اعتماد بصري شامل أو WCAG أو اختبار جهاز فعلي قبل نتائج القبول.
